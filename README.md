
# Airbnb Clone 🏡

This is a full-stack Airbnb clone built using modern web technologies. It features user authentication, property listings, review functionality, and a responsive UI.

## 🔧 Tech Stack

- **Backend**: Node.js, Express
- **Frontend**: EJS Templates, Tailwind CSS
- **Database**: MongoDB (via Mongoose)
- **Authentication**: Passport.js (Local strategy)
- **Others**: Cloudinary for image uploads, Multer for file handling

## 🚀 Features

- User signup, login, and logout
- Host can create, edit, and delete property listings
- Guests can browse listings and leave reviews
- Authentication and authorization middleware
- Responsive UI for mobile and desktop
- Cloud-based image storage (Cloudinary)
